# whynaiwa

一个介绍奶蛙、网友创作和「奶蛙主义」的静态网站。

## 页面

入口为 `index.html`，自动跳转到 `encyclopedia.html`。正文包括：

1. 这是什么？
2. 什么是奶蛙？
3. 为什么大家喜欢奶蛙
4. 写在后面

正文后附小红书账号介绍。页面中的模型作者和模型来源链接保留在正文内。

## 本地预览

安装 Python 后，在项目目录运行：

```sh
python -m http.server 4174 --bind 127.0.0.1
```

访问 http://127.0.0.1:4174/encyclopedia.html 。也可使用其他静态文件服务器。

## 文件

- `encyclopedia.html`：当前主页面。
- `research.css`、`naiwa.css`：页面样式。
- `research.js`：本页搜索、目录与复制链接。
- `assets/`：图片资源。
- `奶蛙网站文案初稿.txt`：文案原稿。

项目内还包含早期页面和样式文件。角色、图片及模型的相关权利归各自权利人所有；上传本仓库不代表对这些素材另行授予许可。
